# 🎵 Music Player Project

## Описание проекта

Данный проект представляет собой демо-версию музыкального плеера
Я создал его как альтернативу программе soundpad т.к. мне не нравится работа с файлами где если вы перемещаете файл в другую директорию то он перестает работать в плеере в моём плеере работа с файлами производится с помощью копирование выбранного пользователям файла в папку "media" от куда с ним и ведется работа в плеере

* **Сервер (Backend):**
 Реализован на **FastAPI** с использованием **SQLAlchemy** для базы данных (SQLite). Отвечает за аутентификацию (JWT), аналитика данных и Real-Time общение через WebSockets (Чат)
(некоторые пункты в процессе разработки по причинам нахождения программы в бета версии).

* **Клиент (Frontend):**
 Реализован на **Tkinter**. Представляет собой графический интерфейс с функциями плеера, аналитики, чата и сменой темы.



# 🛠️ 1. Требования и Подготовка

### ⚠️ Важное замечание по Python, Музыке и Медиа

Проект лучше всего работает на **стабильных версиях Python (3.11 или 3.12)**.

Музыка для примера работы плеера находится в папке **Check_Music**.

Медиа это хранилища для музыке пользователя(1.txt необходимость для гитхаба)

## 1.1 Создайте и активируйте виртуальное окружение (рекомендовано):

    # Создание окружения
    python -m venv venv 
    
    # Активация (Windows)
    .\venv\Scripts\activate


## 1.2 Установите все зависимости для работы плеера

    Пропишите следующую команду в терминале вашего текстового  редактора/IDE:

    pip install -r requirements.txt
    


# 🚀 2. Запуск Проекта

Проект состоит из двух частей, которые должны быть запущены 
**В двух разных терминалах поэтому запустить их перед выполнением следующих пунктов**.

## 2.1 Запуск Backend (Сервер)

Запустите сервер FastAPI с помощью Uvicorn.

1.  Убедитесь, что виртуальное окружение активно.

2.  Выполните команду в **ПЕРВОМ ТЕРМИНАЛЕ** (находясь в корневой папке проекта):

    uvicorn server.main:app --reload

## 2.2 Запуск Client (Клиентское приложение)

1.  Откройте **ВТОРОЙ ТЕРМИНАЛ**.

2.  Выполните команду:

    python -m client.app

* После выполнения этой команды должно открыться графическое окно приложения с формой авторизации/регистрации.
Если возникли ошибки просмотрите пункты занова
Если даже при этом музыкальный плеер не запустился...
От лица разработчика(меня) приношу извинение и говорю что проект в бете 


# 📚 Структура проекта

```text
MusicPlayerProject/
│
├── backend/                       # Серверная часть (API + БД + логика)
│   │
│   ├── __init__.py                # Помечает папку как Python-модуль
│   ├── auth.py                    # Авторизация, регистрация, JWT токены
│   ├── database.py                # Подключение к базе данных и создание сессий
│   ├── models.py                  # ORM-модели SQLAlchemy (User, Track и др.)
│   ├── repositories.py            # CRUD-логика: работа с моделями и запросами
│   ├── schemas.py                 # Pydantic-схемы: структура входных/выходных данных API
│   └── main.py                    # Главная точка запуска FastAPI приложения
│
├── client/                        # Клиентская часть (десктоп-приложение)
│   │
│   ├── __init__.py                # Модуль клиента
│   ├── api_client.py              # Клиент для общения с backend через HTTP
│   ├── app.py                     # Главный файл запуска UI-клиента
│   │
│   └── ui/                        # Файлы интерфейса Tkinter
│       │
│       ├── __init__.py            # Модуль UI
│       ├── main_player_frame.py   # Основной интерфейс музыкального плеера
│       ├── tkinter_styles.py      # Дизайн
│       └── login_frame.py         # Окно входа / регистрации
│
├── media/                         # Каталог для аудиофайлов.
│   │
│   ├── global                     # Общий список песен
│   └── personal                   # Пользовательские списки песен
│
│
├── chat_history.json              # Локальное хранение чата
│
├── favorites.json                 # Локальное хранение избранных песен
│
├── README.md                      # Описание проекта и инструкция по запуску
│
└── requirements.txt               # Список зависимостей Python
```
